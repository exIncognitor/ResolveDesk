# 账号与权限申请（演示知识库）

本知识库用于本地学习演示，不代表真实企业的制度或服务承诺。

## 账号锁定

连续登录失败引起账号锁定时，使用企业官方自助解锁入口，或者向 IT 支持提交 access 类工单。不要将账号密码、验证码、API Key 粘贴到工单里。

## 仓库权限

申请 Git 仓库访问权限时，需要注明资源 ID、权限用途、期望权限级别和有效天数。模拟目录中的资源可通过权限申请流程提交：申请人核对草稿确认后进入待审批，其他 IT 操作员批准后再执行模拟开通。确认和批准都不等于已经开通。此流程仅修改本地模拟权限表；真实企业权限仍需管理员在企业系统中操作。具体资源范围、期限和状态见《权限审批与审计》文档。

## 无法重置密码

如果官方重置入口不可用，记录错误提示和发生时间，申请人工协助。客服不会索要旧密码或一次性验证码。
