# 网络与终端排障（模拟企业制度）

所有规则为合成学习资料；不代表真实企业运维承诺。

## DNS 解析失败

浏览器提示域名无法解析时，先确认影响单一域名还是全部域名，记录时间、网络环境及脱敏错误。使用系统只读诊断查看 DNS 配置与解析结果，核对企业下发的配置。不要自行切换公共 DNS 访问内部域名。外网正常而内网域名失败时，核对 VPN 连接状态和企业 DNS 策略。

## WiFi 频繁断连

记录设备系统版本、无线网络名称、故障时段与影响人数。比较有线或经批准的其他网络，检查是否仅此设备异常。不索要无线密码，不建议擅自重置整个网络或关闭安全软件。多设备同时故障时升级网络值班人员。

## 终端蓝屏与磁盘异常

记录蓝屏停止码、发生频率、系统版本和最近驱动更新。优先保护工作资料，避免重复强制断电和自行格式化。磁盘异响、频繁读写失败或存在数据丢失风险时停止高强度操作，转设备维修并记录资产 ID。

## 安全事件与大面积故障

发现账号泄露、可疑远程控制或大面积断网，优先联系企业安全或 IT 值班人员。通过获准渠道提供时间、影响范围和脱敏证据，不上传密码、验证码、完整日志密钥。Agent 只整理升级信息，不宣称已经隔离设备或恢复网络。
