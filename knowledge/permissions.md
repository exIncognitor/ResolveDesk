# 权限审批与审计（模拟企业制度）

本文件和资源目录均为模拟学习材料；授权只更改本地模拟权限表，不会访问 GitHub 或真实企业账号。

## 可申请资源与最小权限

repo-resolvedesk 允许 read、write；docs-internal 仅允许 read。有效期为 1 至 30 天，必须由申请人提供资源 ID、用途、权限级别和有效天数。不能申请 admin、永久权限或目录以外的资源，不得代替用户选择更高权限。

## 审批与开通流程

草稿确认后进入 pending_approval。申请人不能审批自己的申请；其他 support 操作员可 approve 或 reject 并填写说明。approve 后为 approved，还须执行 provision 才进入 fulfilled 并写入模拟权限表。批准不等于已开通。拒绝后为 rejected；申请人在待审批阶段可以取消为 cancelled。

## 有效期与审计

授权有效期从 provision 时开始计算，到期权限不再出现在有效权限查询中。每一步记录操作者、时间、前后状态和处理说明。不同租户和不同申请人的记录按身份隔离，普通用户不能读取他人申请。审批接口使用版本号防止覆盖并发更新，用幂等键防止重复执行。

## 账号解锁与敏感操作

账号解锁和重置密码遵循官方身份核验渠道；目前仅提供知识解答与普通 access 工单登记，不自动修改密码。任何情况下都不应要求用户提供旧密码、验证码或 API Key。
