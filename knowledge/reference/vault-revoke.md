# License Vault回收与再次获取区别

管理员回收后许可可供其他用户使用，但回收本身不等于禁止原用户再次申请；需要结合分发访问规则。手动回收次数可能受方案限制，运行中的IDE也可能发起新请求。不能套用ResolveDesk模拟回收逻辑推断真实厂商效果。
