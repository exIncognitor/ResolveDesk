# nslookup指定DNS服务器只读检查

nslookup可查询域名，并可显式指定获批准的DNS服务器。保留查询名、服务器和错误摘要，区分超时、无记录和格式错误。不要把未经允许的内部名称发往公网服务器；查询不等于修改DNS配置。
