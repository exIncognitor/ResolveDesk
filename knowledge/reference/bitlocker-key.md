# BitLocker恢复密钥的官方查找途径

恢复密钥是解锁加密驱动器的敏感信息。先记录恢复界面的密钥ID，再通过官方账号或企业IT核对备份位置；不要把完整密钥发给Agent。Microsoft支持无法重建遗失的密钥，不能承诺绕过加密或通过格式化保留数据。
