# License Vault容量通知与采购边界

管理员可使用License Vault的容量通知了解许可用量变化。通知用于提醒核验容量，不能据此声称采购已完成或席位一定可立即分配。阈值和收件人由管理员按所用方案配置；本项目不会自动发送厂商邮件。
