# Windows电池报告与续航记录

powercfg /batteryreport可生成电池使用报告，帮助记录容量与使用变化；报告不是硬件保修结论。生成前确认保存位置，分享时脱敏设备信息。若已出现电池变形等明显风险，应先停止使用并联系IT，不为收集报告继续运行。
