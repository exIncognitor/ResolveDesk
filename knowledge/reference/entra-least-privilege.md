# Entra最小权限与限时角色

授权需要同时限定权限集合、资源范围和时间。优先满足任务所需的较小角色，避免把全局管理员当作普通排障办法。PIM等能力的可用性取决于企业产品与配置；ResolveDesk模拟目录不代表真实Entra授权。
