# 软件授权与席位（模拟企业制度）

本文件为学习项目构造的模拟制度，不是任何真实企业政策，不承诺真实库存或采购时效。

## 软件白名单

VS Code 可以按软件白名单安装；商业插件需单独核验许可证。禁止使用破解软件，禁止把个人账号和企业共享账号互借。安装前确认操作系统、软件版本与工作用途。

## IDEA 商业授权

IntelliJ IDEA Ultimate 使用企业命名用户席位；模拟目录初始有 2 个可用席位。申请应提供产品、工作用途、使用期限和主管审批。目录中的数量是演示库存；本系统可以查询和记录申请，不会直接向厂商购买或分配真实许可证。没有席位时进入采购审核，不能承诺立刻开通。

## 许可证到期与离职回收

软件提示授权到期时先核对企业账号、产品版本与到期日期，勿粘贴授权码。离职、转岗或不再需要使用时，应由 IT 管理员回收席位并记录审计。个人先行购买不自动获得报销资格，费用须按审批结果处理。

## 无法激活

记录脱敏错误提示、产品版本、账号所属组织和发生时间，核对网络及官方激活服务可达性。避免关闭防火墙或分享激活密钥；仍不能解决时提交 software 工单，按授权规则人工核验。
