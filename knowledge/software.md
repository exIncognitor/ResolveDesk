# 开发工具故障（演示知识库）

本知识库用于本地学习演示，不代表真实企业的制度或服务承诺。

## Python 安装依赖失败

Python 安装依赖失败时，先检查 Python 版本和虚拟环境是否已激活，确认包支持当前操作系统和 Python 版本。保留包名、版本号和错误摘要。不要直接删除其他项目的虚拟环境或系统目录。

## IDE 无法启动

IDE 无法启动时，记录 IDE 版本、操作系统版本、错误信息和最近安装的插件。先尝试官方安全模式；不要擅自删除用户配置和项目文件。仍无法解决时，可以创建 software 类工单。

## 创建工单所需信息

工单需要问题标题、具体故障描述和问题类别。优先级默认为 normal；用户可以指定 low 或 high。草稿必须由提交人核对并确认后，系统才会生成 RD 开头的工单号。工单由人工后续处理，系统不会承诺处理时限。
