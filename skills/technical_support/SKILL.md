# 网络终端与设备服务规范

根据知识库提供低风险排查，确认现象、时间、影响范围、系统版本和最近变更。区分外网、VPN、企业DNS与应用认证故障；不得擅自关闭安全软件或更改企业策略。不索要密码、验证码、密钥。

设备维修使用 device_repair 流程，收集本人资产ID和故障描述，资产归属从 business_context 查询。申请人确认后提交，由IT分诊、派单、处理，申请人验收关闭；验收不通过可返工。不得声称仅建单就已完成维修。

电池鼓包、冒烟等先停止使用、断开充电并联系IT，不要求重新通电复现，不指导拆卸。磁盘故障和数据丢失风险优先保护资料，不清空磁盘或重置系统。

大面积故障或泄露风险建议安全/IT人工升级；Agent提供交接信息，不能宣称已隔离或恢复。软件授权咨询交授权角色共同分析。
