# 第三轮推进记录

目标及边界见 `ITERATION3_GOAL.md`。Python 是唯一后端；继续使用 Vue、PostgreSQL、Redis、Chroma、MCP、Prometheus、Docker。模型仅 DeepSeek Flash，检索优化 always、专业节点 full；没有启用 adaptive 或专用重排服务。

## 已实现

- 字面实体提取保留原文位置与用户轮次，支持中文/阿拉伯/全角整数天数、独立字段更正、撤回、多候选、任务取消与切换。关键申请字段不允许由模型补造；摘要、分类和目录映射明确标为派生内容，缺省值不冒称用户输入。草稿来源与草稿在同一 SQL 事务保存。
- 26 篇助手自写的官方技术参考，覆盖四类现有 IT 场景。来源为 Microsoft、JetBrains、Python、pip；正文与来源目录固定在 `knowledge/reference`。它们不能替代真实企业制度。
- 独立发布表及审计表；新受管理内容默认草稿，内容/元数据修改均重新进入草稿。客服以内容版本和元数据版本审核发布/撤回。租户与私有所有者隔离继续生效，Agent 只有读取能力。
- SQL 当前状态和数据库时钟控制检索、引用、统计、缓存与评测快照；Chroma outbox 负责移除不可用材料与定时生效/到期投影。延迟失败重试与未来生效任务分开报告。暖 Redis 缓存跨独立进程撤回验证已通过。
- Vue 知识页提供来源、适用范围、状态、版本、元数据编辑与审核审计入口，引用弹窗显示发布材料信息。
- 保留旧无元数据文档的兼容读取；发布工具会给内容与版本完全匹配的 8 篇原始示例补上“模拟制度”标记，不覆盖用户修改过的文档。
