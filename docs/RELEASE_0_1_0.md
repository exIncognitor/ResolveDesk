# ResolveDesk 0.1.0

本次发布提供面向内部IT服务的Python Agent、Vue工作台，以及MIT开源许可。

## 工作台

- 独立的深蓝导航与蓝色操作体系，围绕员工服务重新组织欢迎页。
- 账号权限、设备维修、软件授权、网络排障四个快捷入口。
- 业务服务台显示当前身份的申请、可处理事项、结束流程和设备概览。
- 申请卡片、状态标签、本人资源、操作审计与手机布局。
- 对话中的草稿以可读字段展示，并可跳转业务进度。

## 服务与工程能力

权限申请、设备维修和软件席位均有持久化状态、角色校验、事务审计和幂等动作；结合混合RAG、知识发布治理、多轮字段、专业角色、私有记忆、MCP、恢复和费用网关。

本次保持Python业务引擎不变；此前 `resolvedesk-demo-v1` 标签保留。界面和文档在该基础上更新。

## 验证

前端42项回归及构建通过。1280px桌面与390px手机工作台、服务记录、资源数据和快捷入口在浏览器核验；快捷入口只填入需求，不自动发送收费调用。

此前真实三服务463项及14子测试、三条业务演示11/11与Flash两轮结果见 [业务引擎验收](FINAL_POLISH_ACCEPTANCE.md)。本次未为界面与文档重复调用付费模型。
