# 功能范围核对

核对日期：2026-10-26。结论：**当前不能声称已等价覆盖原项目所有功能，再加上全部改进。**

主入口是 `resolvedesk/app.py`。兼容入口 `api/main.py` 与相关类仍保留；类和测试存在不代表该功能已进入新主入口。

| 能力 | 当前主入口实际状态 | 证据与限制 |
| --- | --- | --- |
| Vue 对话、知识库、任务页面 | 已接入 | 浏览器确认建单、恢复任务、查看记忆与 MCP；Python 为当前服务，独立 Java 后端未迁移 |
| 查询改写、结构化分块、混合召回、RRF、Flash 重排 | 已接入 | `resolvedesk/services.py`、`retrieval.py`；有本地与小规模真实请求，重排失败有回退 |
| 意图识别与多角色处理 | 已接入 | 复用角色和路由；复合请求真实并行执行专业节点；不代表所有原业务场景等价迁移 |
| 摘要、用户画像与跨任务记忆 | 已接入受限版本 | SQLite 摘要和语义历史；当前画像主要抽取显式 OS/IDE，未等价迁移原来的完整画像提炼 |
| Skills | 已接入 | 按角色/关键词注入并支持重载 |
| 标准 MCP | 已接入一条实际链路 | 标准 stdio 白名单只读诊断工具已验证；通用外部服务配置和旧 HTTP 服务端链路未在新入口完整验收 |
| 工单草稿、追问、确认、幂等与权限 | 已接入 | 本地事务建单和查询；没有企业平台的分派、处理、关闭集成 |
| 持久化检查点、暂停恢复、SSE 文本与进度 | 已接入 | 已保存模型结果与工具轮次可复用；未完成的模型请求可能需要重发并再次收费 |
| 费用、Token 与超时控制 | 已接入 | 只允许 Flash，共用累计账本；不是服务商账号级硬消费限额 |
| 检索评测与人工审核反馈回归 | 已接入 | 当前 UI 执行检索和已审核案例，不是完整回答质量评分 |
| 原完整意图/多轮端到端评测、LLM Judge 与基线回归 | 新主入口未接入完整流程 | `evaluation/evaluator.py` 保留并有回归测试，不能据此称新主入口已提供完整质量评测 |
| 原 Prometheus、告警、监控反馈降权 | 新主入口未完整接入 | 当前 `/monitor` 主要为角色运行统计；`tool_stats`、`active_alerts` 等不代表原完整监控系统已运行 |
| 原 Redis/Chroma 存储与并发租约 | 兼容链路保留 | 新主入口采用单进程 SQLite，没有做该旧链路的完整无容器集成验收或集群压测 |
| 原订单、物流、会员、账单等业务场景 | 未等价迁移为当前业务 | 当前定位为内部 IT 支持；角色保留不等于这些业务已全部接入 |
| Docker | 按要求跳过 | 配置存在，未构建或运行验收 |
| 专用重排模型比较 | 按要求不做 | 当前仅使用 Flash 重排 |

现有测试和报告证明的是相应范围内的本地实现，不是对“全部功能”“生产可用”或泛化效果的证明。

## 版本留存

本项目自本轮起使用 Git 提交替代相邻 history 文件夹。Git 只能恢复已进入提交的版本；未提交改动、忽略的数据库、费用账本、模型和密钥仍需独立保护。上传范围按用户确认的授权处理，当前默认私有仓库。
