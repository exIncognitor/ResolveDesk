核对日期：2026-10-27。已补入 IT 四类场景、两条模拟业务闭环、质量评测与本地监控告警。**原版技术迁移仍有明确差异，不能声称全部等价覆盖。** 实现与运行方法见 `IT_SERVICE_DESIGN.md`。

**迁移结论以 [完整技术审计](MIGRATION_AUDIT_2026-10-27.md) 为准。** 下文“已接入”仅指相应本地能力存在，不能解释为原版所有子能力已等价迁移。完整审计已固定 G01–G13 对齐范围、全部原运行模块与接口去向。

主入口是 `resolvedesk/app.py`。兼容入口 `api/main.py` 与相关类仍保留；类和测试存在不代表该功能已进入新主入口。

## 版本留存

本项目自本轮起使用 Git 提交替代相邻 history 文件夹。Git 只能恢复已进入提交的版本；未提交改动、忽略的数据库、费用账本、模型和密钥仍需独立保护。上传范围按用户确认的授权处理，当前默认私有仓库。
