# 功能范围核对

核对日期：2026-10-27。已补入 IT 四类场景、两条模拟业务闭环、质量评测与本地监控告警。**原版技术迁移仍有明确差异，不能声称全部等价覆盖。** 实现与运行方法见 `IT_SERVICE_DESIGN.md`。

**迁移结论以 [完整技术审计](MIGRATION_AUDIT_2026-10-27.md) 为准。** 下文“已接入”仅指相应本地能力存在，不能解释为原版所有子能力已等价迁移。完整审计已固定 G01–G13 对齐范围、全部原运行模块与接口去向。

主入口是 `resolvedesk/app.py`。兼容入口 `api/main.py` 与相关类仍保留；类和测试存在不代表该功能已进入新主入口。

| 能力 | 当前主入口实际状态 | 证据与限制 |
| --- | --- | --- |
| Vue 对话、知识库、任务页面 | 已接入 | 浏览器确认建单、恢复任务、查看记忆与 MCP；Python 为当前服务，独立 Java 后端未迁移 |
| 查询改写、结构化分块、混合召回、RRF、Flash 重排 | 已接入 | `resolvedesk/services.py`、`retrieval.py`；有本地与小规模真实请求，重排失败有回退 |
| 意图识别与多角色处理 | 部分迁移，已适配 IT 职责 | 当前最终业务意图/主路由由规则决定，未完整保留三路融合驱动路由；普通与复合请求的原故障回退、专业节点共享工具等仍有差异；见G01/G03/G04 |
| 摘要、用户画像与跨任务记忆 | 已接入受限版本 | SQLite 摘要和语义历史；当前画像主要抽取显式 OS/IDE，未等价迁移原来的完整画像提炼 |

| 工单草稿、追问、确认、幂等与权限 | 已接入，续聊回执未齐 | 本地事务建单和确认幂等、专用业务状态已验证；/reply缺少独立逐轮请求键与回执，不能概括为所有对话回合均等价防重放；见G12 |
| IT 业务覆盖与领域知识 | 已接入 | 账号权限、网络终端、软件授权、设备服务；7 篇模拟知识文档；软件席位为静态演示目录 |
| 权限审批与模拟开通 | 已接入 | 本人确认、禁止自批、审批与开通分离、期限、模拟权限表、并发版本和幂等 |
| 设备维修与验收返工 | 已接入 | 资产归属与占用检查、分诊派单、处理、本人验收/返工、释放资产；不接真实供应商 |
| 持久化检查点、暂停恢复、SSE 文本与进度 | 已接入 | 已保存模型结果与工具轮次可复用；未完成的模型请求可能需要重发并再次收费 |
| 费用、Token 与超时控制 | 已接入 | 只允许 Flash，共用累计账本；不是服务商账号级硬消费限额 |
| 检索评测与人工审核反馈回归 | 已接入 | 20 条合成固定题与人工审核回归；不消耗模型费用 |
| 意图/多轮质量评测、LLM Judge 与基线回归 | 已接入受限替代链路 | 28条测的是IT规则分类；6组多轮对话仅最终回复Judge；原三路识别评测、自定义用例、逐轮评分与泛化断言等未完整迁移；业务状态、四维Judge、人工基线、持久任务已接入；见G08 |

| 原 Redis/Chroma 存储与并发租约 | 兼容链路保留 | 新主入口采用单进程 SQLite，没有做该旧链路的完整无容器集成验收或集群压测 |
| 原订单、物流、会员、账单等业务场景 | 未等价迁移为当前业务 | 当前定位为内部 IT 支持；角色保留不等于这些业务已全部接入 |
| Docker | 按要求跳过 | 配置存在，未构建或运行验收 |
| 专用重排模型比较 | 按要求不做 | 当前仅使用 Flash 重排 |

现有测试和报告证明的是相应范围内的本地实现，不是对“全部功能”“生产可用”或泛化效果的证明。

## 版本留存

本项目自本轮起使用 Git 提交替代相邻 history 文件夹。Git 只能恢复已进入提交的版本；未提交改动、忽略的数据库、费用账本、模型和密钥仍需独立保护。上传范围按用户确认的授权处理，当前默认私有仓库。
