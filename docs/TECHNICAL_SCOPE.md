# ResolveDesk 技术范围

本文定义当前 Python IT 服务台的技术范围。当前架构入口为 [CURRENT_ARCHITECTURE.md](CURRENT_ARCHITECTURE.md)，已观察结果和限制见各版本验收。目录或依赖存在不等于当前运行入口已接入。

| 范围 | 实际入口与责任 |
| --- | --- |
| G01 意图链路 | Flash/E5/规则融合、低置信澄清、紧急度与角色路由 |
| G02 多轮状态 | 字面字段、来源跨度、纠错、任务切换和服务端申请契约 |
| G03 专业编排 | 普通/复合咨询、实例选择、冷却探测、回退与实际角色 |
| G04 专业工具 | 角色白名单、本人资产/资源目录、RAG、只读诊断及交接 |
| G05 记忆 | SQL 来源、Redis 工作上下文、私有 Chroma 分段与有界维护 |
| G06 检索可靠性 | BM25/E5/Chroma/RRF、缓存、失效、超时、熔断和引用复核 |
| G07 MCP | 配置化 stdio/HTTP、重连刷新、鉴权知识工具与资源、只读限制 |
| G08 质量评测 | 当前识别器、逐轮评判、确定性断言、隔离沙盒和有效基线 |
| G09 监控 | 主执行/实际角色/工具耗时、持久指标、告警 outbox 与反馈 |
| G10 调用轨迹 | 参数脱敏、结果摘要、实际时间、轮次与执行代次分页 |
| G11 操作入口 | 统一 Vue/CLI/HTTP、批量原子导入与受限 multipart |
| G12 状态与并发 | PG 事务、逐轮回执、SQL 代次保护、Redis 租约和评测保留 |
| G13 部署 | 同源前端、应用/网关/PG/Redis/Chroma/Prometheus、备份与恢复 |

四类业务为账号权限、网络终端、软件授权、设备服务。三条模拟事务流程为权限审批开通、设备维修验收返工、商业席位预占分配回收。模型可读取和准备草稿；确认、审批和资源写入必须经过授权接口。

真实企业 IAM、供应商维修、厂商许可和外部告警送达属于后续集成范围。专用重排比较、Java 独立后端和生产集群容灾不在本次范围。项目采用 [MIT 许可证](../LICENSE)。
