# 展示版本收尾目标

基线 507f997。固定顺序：文档整理 → Vue 请求竞态 → 小范围质量优化 → 三条完整模拟演示 → 部署及展示版本冻结 → 项目学习教材。

不新增业务域、框架、基础设施或外部写入。Python 单后端，Flash、always 检索和 full 编排保持默认。原共享累计预算 20 元保留 2 元，本次新增调用上限 2 元，先读取实际账本并使用更严格进程上限；不重置消费。

文档整理退役过时的产品比较入口，保留来源/版权/授权记录和原始验证证据。普通文件使用 Git 检查点，教材位于 agentlearn 独立新目录；凭据、模型、数据库、历史和其他项目保持受保护。

必须修复：确认、查看、恢复、暂停和反馈在身份/会话切换后的过期结果；恢复流可取消，旧操作不能覆盖新状态或误归属。必须验证同会话成功、延迟响应、切换身份/任务、旧错误和新忙状态。

质量优化：区分申请对象和用途中的附带提及；追问只问必要缺项；对缺少依据和紧急交接提供简洁、针对性的有来源回答。原冻结材料/标签/失败报告保留；新增独立开发与验收输入，不降低评分。

完整演示 learner/support 的权限、维修（含返工）和席位（含回收）流程，检查落库与界面；默认免费回归，真实 Flash 调用遵守本次 2 元预算。备份后更新两个入口，保存源/前端一致性证据；私有 GitHub 最终交付提交四项 CI 全通过后冻结。

按获准的 project-learning-playbook 编写教材，覆盖业务、代码、技术原理、失败与取舍、面试连续追问及体验；以冻结代码为准，唯一学习地图、概念唯一归属，代码链接和导航可用。教材通过相称验证后结束，不自行增加下一轮目标。
